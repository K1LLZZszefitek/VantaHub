VANTA HUB — START
1. Zainstaluj Node.js LTS.
2. W .env wpisz lokalnie token bota, Client Secret OAuth2 i ID kategorii ticketów.
3. W terminalu w tym folderze: npm install
4. Potem: npm start
5. Otwórz http://localhost:3000
Redirect URI w Discord Developer Portal: http://localhost:3000/auth/discord/callback
Bot potrzebuje: View Channels, Send Messages, Read Message History, Attach Files, Embed Links, Manage Channels.
